# Production Grade CI/CD Pipeline for 3-Tier Application

This project demonstrates a production-level DevOps CI/CD pipeline using:

- AWS (EC2)
- Terraform
- Ansible
- Jenkins
- Docker & Docker Hub
- Kubernetes (Minikube)
- Prometheus & Grafana

## Architecture
- 3-tier application (Frontend, Backend, Database)
- Jenkins-driven CI/CD pipeline
- Kubernetes-based deployment
- Monitoring and observability
